# ubiquant 的编程助手（编程导师 v1.1）

一个面向**零基础到进阶**的编程导师人格预设，用于 DSH（DeepSeek Harness）。C++/Python 双语言，题目以[洛谷](https://www.luogu.com.cn/)为准，引导式教学——帮你建立编程思维、认清自己的问题，**而不是替你解题**。

> 版本：v1.1　｜　语言：C++（默认 C++20）/ Python　｜　平台：Windows

---

## 功能

- **首次阶梯式诊断定级**：分领域（语法 / 数据结构 / 算法）用「最小任务」测你**会不会做**，产出能力画像，据此给出落在「最近发展区」的低门槛首题。
- **引导式教学**：要答案才给；debug 给方向、给会报错的样例、给断点/日志位置，**不直接给正确代码**；概念讲一次、需复习时设问式提问，培养编程思维。
- **里程碑推进 + 严格 AC 闸门**：一次一题，解锁更难的里程碑/题目必须你在洛谷**真实 AC**；自报「我会了」不解锁。
- **双语言**：首次运行时选定 C++ 或 Python 并锁定，中途不可更换。
- **评测机模式**：精确输入「评测机模式」进入——英文题截屏**只翻译不解答**；输入样例+程序**只模拟输出该程序的结果**，其余一字不出。该模式的作答与诊断**与教练模式同步**，切回后可个性化指导。
- **周期性反馈**：里程碑收尾 AC 后给简短小结；长期进度以知识图谱持久化。

## 怎么切换模式

| 动作 | 输入 |
|---|---|
| 进入**评测机模式** | 精确发送：`评测机模式`（五个字，**不会自动切换**） |
| 切回**教练模式** | 发送：`教练模式` 或 `退出评测机模式` |

> 两种模式详见 [初次使用引导.md](初次使用引导.md)。

## 初次使用（三步）

1. **安装**（把「人格预设」装进 DSH、「知识图谱」放进工作区数据目录，命令见下）。
2. **开新会话**，在预设列表里选「**ubiquant 的编程助手**」。
3. 它会依次：讲清工作契约 → 让你选 C++/Python → 探测环境（没有就引导你搭）→ 阶梯诊断定级 → 给一道低门槛首题（如 P1000），**只给思路**。你把代码提交洛谷、回报结果，它据此推进。

> 详细步骤（安装、目录结构、两种模式、常见问题）见 **[初次使用引导.md](初次使用引导.md)**。
