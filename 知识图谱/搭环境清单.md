# 搭环境清单（搭环境里程碑读取；指令式直接教）

> 触发：用户无环境且零基础 → 把「搭环境」作为第一个里程碑。直接一步步教，用户执行，教练不替跑。
> 原则：存对编码 → 编译器到位 → 开关/版本对 → hello world 验证通过。
> 用 web_fetch 拉官方文档核对当前步骤（版本号、界面可能变）。

## 通用第一步
1. 确认操作系统（本预设默认 Windows；若用户实际是其他系统，按其系统调整）。
2. 确认要搭的语言（C++ 或 Python，首次已选定）。
3. 准备好一个写代码的编辑器/IDE（见下）。

---

## C++ 环境（Windows，面向工作 + C++20）
### 推荐：Visual Studio 2022（社区版免费）
1. 下载 **Visual Studio 2022 社区版**（web_fetch 查最新官方下载入口）。
2. 安装时**勾选「使用 C++ 的桌面开发」工作负载**（含 MSVC 编译器 + Windows SDK）。
3. 装完打开 VS → 创建「C++ 控制台应用」。
4. **关键开关**：
   - 项目属性 → C/C++ → 语言 → **C++ 标准 → ISO C++20 标准（`/std:c++20`）**。
   - 源文件**保存为 UTF-8**（避免中文注释/输出乱码）：文件「高级保存选项」选 **Unicode (UTF-8 无签名)**；或加 `/utf-8` 编译选项。
5. **验证**：写最小程序，编译运行，看到预期输出：
   ```cpp
   #include <iostream>
   int main() {
       std::cout << "hello C++20\n";  // 用 \n，不用 endl
       return 0;
   }
   ```
6. 在洛谷提交 P1001（A+B）验证 AC。

### 备选：VS Code + MinGW-w64（g++）
1. 装 VS Code + C/C++ 扩展。
2. 装 **MinGW-w64（g++ 13+）**，把 `bin` 加入 PATH。
3. 终端验证：`g++ --version`（应显示 13+）。
4. 编译：`g++ -std=c++20 -O2 main.cpp -o main`（`-O2` 用于洛谷）。
5. **中文编码**：源文件存 UTF-8；若乱码，编译加 `-finput-charset=UTF-8` 或加 `/utf-8` 思路。
6. 洛谷 P1001 验证 AC。

> ⚠️ 洛谷评测机为 GNU++17/20，本地用 g++ 时尽量贴近；提交语言选 **C++20（或 C++17）**。
> ⚠️ C++20 部分特性各编译器支持不一；用某特性前 web_fetch/查文档确认，拿不准就说明「该特性需较新编译器」。

## Python 环境（Windows）
### 推荐：Python 官方 3.12+
1. 下载 **Python 3.12+**（web_fetch 查 python.org 下载页），安装时**勾选「Add python.exe to PATH」**。
2. 验证：`python --version`（显示 3.12+）。
3. **验证运行**：
   ```python
   print("hello Python")
   ```
4. 编辑器：VS Code + Python 扩展，或 PyCharm社区版。
5. 洛谷提交语言选 **Python（Python2/3）**，先 P1001 验证 AC。

### Python 性能与洛谷提示
- 大输入用 `sys.stdin.readline` 加速（纯新手点到为止，先跑通）。
- 深递归可能触发 RecursionError，必要时 `sys.setrecursionlimit`。
- 部分题 Python 因解释速度可能 TLE 而 C++ 能过 → 这是语言速度差，不是用户错；如实告知，让用户决定是否换思路或接受。

## 常见坑（讲一次）
- 「找不到 g++/cl」→ PATH 没配 / 编译器没装。
- 中文乱码 → 源文件编码非 UTF-8，或输出函数编码不符。
- C++ 报「`/std:c++20` 不支持」→ 编译器版本旧，升级或改用 `/std:c++17`。
- Python「python 不是命令」→ 安装时没勾 Add to PATH。
- 本地过了但洛谷 WA/RE → 不是环境问题，转判题错误流程（见 错误成因表.md）。
