# 术语词典（零基础速查）

> 教练在讲解或用户发问时按需引用；面向工作需求，解释要落到「这是什么、什么时候用、有什么坑」。

## 判题与平台
- **洛谷**：国内 OJ（在线评测）平台，题目可在线提交、即时评测。本预设的题源。
- **题号**：洛谷每道题的唯一编号，如 `P1000`。
- **评测（判题）**：提交代码后由评测机运行、返回结果的过程。
- **AC**：Accepted，通过。本题全部测试点通过。
- **WA**：Wrong Answer，答案错误。能编译能跑，但输出不对。
- **TLE**：Time Limit Exceeded，超时。算法太慢或死循环。
- **MLE**：Memory Limit Exceeded，超内存。数据结构开太大或递归太深。
- **RE**：Runtime Error，运行时错误。程序跑起来后崩溃（越界、除零、空指针等）。
- **CE**：Compile Error，编译错误。代码没过编译，根本没运行。
- **PE**：Presentation Error，格式错误。内容对但输出格式（空格/换行）不对。
- **OLE**：Output Limit Exceeded，输出超限。

## 语言与编译
- **C++**：本预设支持的两种语言之一，信奥/竞赛主流，工作场景也常用。
- **Python**：本预设支持的另一种语言，语法简洁、上手快，工作场景常用。
- **编译器/解释器**：把代码变成能运行程序的工具（C++ 用编译器如 g++/MSVC；Python 用解释器）。
- **标准（Standard）**：语言规范的版本。本预设默认 **C++20**。
- **源码编码**：源文件的字符编码。中文注释/输出在 Windows 上易因编码不符乱码，建议存 **UTF-8**。
- **STL**：C++ 标准模板库（vector/string/algorithm 等）。Python 对应标准库（list/dict/itertools 等）。

## 语法与运行
- **变量/类型**：存数据的容器。C++ 静态类型（须声明类型），Python 动态类型。
- **分支**：if / else，按条件选路。
- **循环**：for / while，重复做事。
- **数组/字符串**：一串连续的数据。C++ 用 array/vector/string；Python 用 list/str。
- **函数**：把一段可复用逻辑打包，有名字、可传参、可返回。
- **递归**：函数自己调用自己，常用于分治/回溯，注意终止条件与深度。
- **指针/引用**：指向内存地址的值（C++ 重点）。Python 无显式指针（有引用语义）。
- **越界**：访问了不存在的位置（如数组下标越界），是 RE 的常见原因。
- **未初始化**：用了没赋初值的变量，值不确定，是常见 bug。
- **整型溢出**：整数超出类型范围（C++ 会回绕；Python 大整数不会）。
- **`=` 与 `==`**：`=` 是赋值，`==` 是比较；C++ 里 if 条件误用 `=` 是经典错误。
- **命名空间**：名字的分组。C++ 的 `std`；`using namespace std;` 方便但工作向有争议（大型项目易命名冲突），遇到再点评。
- **RAII / 智能指针**：C++ 资源管理机制，用对象生命周期管理资源/内存（工作向重要）。
- **输入加速**：C++ 关 `cin/cout` 同步、用 `\n` 代替 `endl`；Python 用 `sys.stdin`。大输入才需要，纯新手点到为止。

## 算法与数据结构
- **算法**：解决问题的一套步骤。
- **数据结构**：组织数据的方式（数组、链表、栈、队列、哈希表、树、图）。
- **排序**：把数据按顺序排列。
- **二分查找**：有序数据上每次折半定位，O(log n)。
- **贪心**：每一步选当前最优，赌全局最优（需证明/验证）。
- **前缀和 / 差分**：区间求和/区间修改的预处理技巧。
- **递归/分治/回溯**：三类递归思维。分治=大问题拆小；回溯=尝试+撤销。
- **搜索**：DFS（深搜，用栈/递归）、BFS（广搜，用队列，最短路）。
- **动态规划（DP）**：把大问题拆成重叠子问题、存结果避免重复算。入门靠「状态定义 + 转移方程 + 初值」。
- **图论**：节点与边组成的结构，BFS/DFS/最短路/最小生成树/拓扑排序等。
- **时间复杂度**：算法耗时的增长量级（O(n)、O(n²)…），TLE 排查靠它。
