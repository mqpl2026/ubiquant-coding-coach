# 诊断阶梯（首次运行定级时读取）

> 用途：用「阶梯式功能诊断」取代概念问答，测用户**会不会做**，而非**认不认识**。
> 三领域分别定级，产出画像 `{语法:Sx, 数据结构:Dx, 算法:Ax}`，不是单一分数。
> 定级结果只决定「从哪一阶给首题」，**不直接在图谱标通过**（标通过要洛谷 AC）。

## 执行原则
- **测做不测知**：给最小任务让他真做；从易往难爬，**爬到做不出为止**，水平=最后做出的那一阶。
- **先夹逼再确认**：先问「你写过循环吗？写过从键盘读数的程序吗？」跳过大段显然会的，再在边界给一个任务确认。真零基础从 S1 起。
- **允许描述做法**：能讲清大致思路也算过一阶（鼓励而非考倒）。但「讲清」仅限定级，**不给解锁**。
- **6–8 阶内收敛**，不让他做完整张卷。
- **自报不算证据**：「我见过递归」只能从那一阶开始测，不能跳级。
- **框定是「热身」不是「考试」**。
- **地板**：连 S1 都做不出（跑不了任何代码）→ 首任务改为「搭环境 + hello world」，跑通再上 P1000。

## 画像 → 首题映射（落在最近发展区，选 low-barrier quick win）
| 画像触发 | 首任务 | 说明 |
|---|---|---|
| 连 S1 都做不出 | 搭环境 + hello world | 地板任务，不上洛谷 |
| 语法停在 S1–S3，DS/算法未起 | **P1000**（超级玛丽，无输入） | 只打印固定图案，练输出+提交+快速 AC |
| 语法到 S3–S5 | **P1001**（A+B）或 P1000 | 引入输入 |
| 语法到 S5–S6（会循环） | P5700/P5704 分类价格类 | 分支+循环巩固 |
| 语法到 S7–S8（会函数） | P5724 求奇数（封装成函数） | 函数应用 |
| 语法到 S9–S10（会结构体/指针） | P5737 结构体基础 | 结构体应用 |
| 算法到 A1–A3（会递推/递归） | P1425 小鱼的游泳时间 / P1085 不乐的周末 | 循环/模拟应用，**不直接上八皇后** |
| 算法到 A4–A5（会二分/排序） | P2249 查找 / P1177 排序模板 | 对应应用 |
| 算法到 A8–A9（会 DFS/BFS） | P1605 迷宫 | 搜索入门 |
| 算法到 A10+（会回溯） | 才轮到 P1219 八皇后 | 八皇后是 A10，前面没到不给 |

> **铁律**：八皇后（P1219，回溯 A10）只应在用户算法画像已到 A10 后才出现。v1.0 的翻车正是「会一点递归」就跳到了 A10。

## 严格度回顾
- 本诊断（聊天做/描述）= **宽松**，做出即算过该阶。
- **首题**要用户**自己在洛谷 AC 坐实**。
- **首题之后**推进 = **严格 AC 闸门**（解锁更难里程碑必须 AC 过一题）。
