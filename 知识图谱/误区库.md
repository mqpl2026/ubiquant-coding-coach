# 误区库（用户反复错同类知识点时读取，专项攻克）

> 触发：同一错误模式在同一知识点出现两次 → 标记 misconception，查本表对应条目，用设问/小练习专项攻克，而非泛泛重讲。
> 条目 = 误区 | 典型表现 | 引导方式（设问优先）。

## C++ 通用
| 误区 | 典型表现 | 引导 |
|---|---|---|
| `=` 与 `==` 混用 | `if (a = 1)` 永远为真 | 问「这里是要比较还是赋值？」 |
| 数组越界 | 下标写到 n 或更大 | 问「最大合法下标是多少？从几开始？」 |
| 整数除法 | `3/2` 得 1，想要小数要转 double | 问「两个 int 相除结果类型是什么？」 |
| 未初始化 | 用了没赋值的变量 | 问「这个变量第一次被读之前赋过值吗？」 |
| 死循环 | 循环变量没更新 | 问「每次循环，循环变量往终止条件靠近了吗？」 |
| 越界递归 | 终止条件缺失/写错 | 问「递归到最小子问题时怎么停？」 |
| endl 滥用 | 大量 endl 导致 TLE/慢 | 问「换行一定要刷新缓冲区吗？`\n` 够不够？」 |

## 算法思维
| 误区 | 典型表现 | 引导 |
|---|---|---|
| off-by-one | 二分/循环边界差 1 | 问「合法区间是 `[l,r]` 还是 `[l,r)`？mid 怎么算？」 |
| 贪心未验证 | 直接套贪心没反例 | 问「你能举一个这贪心会失败的例子吗？」 |
| DP 状态没定义 | 上来就写转移 | 问「`dp[i]` 表示什么？这个问题的最小子问题是什么？」 |
| 复杂度误判 | O(n²) 当 n=1e5 | 问「n 最大多少？两层循环大概多少次？」 |

## Python 专属
| 误区 | 典型表现 | 引导 |
|---|---|---|
| 可变默认参数 | `def f(x, lst=[])` 跨调用累积 | 问「默认参数在函数定义时求值一次，多次调用会怎样？」 |
| 遍历时改容器 | `for x in list: list.remove(x)` 漏删/错删 | 问「遍历时改列表会怎样？要遍历的副本吗？」 |
| 浅拷贝 | `b = a` 以为复制了 list | 问 "`b = a` 是新建一份还是两个名字指向同一对象？」 |
| 递归深度 | 深递归 RecursionError | 问「Python 默认递归深度有限，深了怎么办？」 |
| input 速度 | 大量 input 超时 | 问「读 1e5 行时 input 够快吗？`sys.stdin` 了解吗？」 |
| 闭包延迟绑定 | 循环里 lambda 全取最后值 | 问「循环变量在 lambda 真正被调用时才取值，对吗？」 |

## 字符串/编码（Windows）
| 误区 | 典型表现 | 引导 |
|---|---|---|
| 中文乱码 | 源码/输出中文乱码 | 问「源文件是什么编码？输出函数按什么编码？」 |
| 换行符 | Windows `\r\n` 导致 PE | 问「输出的换行和题面要求一致吗？」 |
